# Record a release

How to add a published version to a resource so it appears on the Releases screen and on the
resource's page. For administrators signed in to the console.

No collector reads releases. Every release is entered by hand.

## Steps

1. Open **Releases** and click **Add release**.
2. Choose the **Resource**. Type to search the list.
3. Type the **Version**, for example `1.4.0`.
4. Choose the **Month** and type the **Year**. They default to the current month.
5. Click **Add release**.

Release dates are kept to the month. The dashboard shows *Aug 2026*, not a day.

## Check it worked

- The release is at the top of **Releases** in the console if it is the newest.
- On the public dashboard, **Releases** counts it in **Releases per month** and lists it under
  **Recent releases** when its month is inside the chosen range.
- The resource's own page lists it under **Releases**.

## Fix or remove a release

Open the **⋯** menu on its row:

- **Edit** changes the version, month or year.
- **Delete release** removes it from the catalog and from the release charts.
